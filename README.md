# AI for Blinds

Nghiên cứu, phát triển hệ thống nhận dạng, diễn giải hình ảnh
ứng dụng mô hình ngôn ngữ thị giác, hỗ trợ học sinh khiếm thị
học tập kiến thức trực quan.

## Các thành phần

- `ai/`: VLM, prompting, STT/TTS và đánh giá mô hình — Phúc.
- `backend/`: API, dữ liệu và triển khai — Nam.
- `frontend/`: Ứng dụng Flutter và trợ năng — Toàn.
- `data/`: Dữ liệu phục vụ nghiên cứu.
- `docs/`: Tài liệu nghiên cứu và thiết kế.
